# Localsewa Android v2.0.12 — Services Action + Bottom Sheet Spacing Hotfix

Apply this incremental hotfix over v2.0.11.

- Provider Services: added a vertical divider between Edit and Remove actions.

- Provider Profile edit sheet uses the same bottom-sheet margin rule.
- Provider Notifications bottom sheet uses the same margin rule.
- Customer Notifications bottom sheet uses the same margin rule.
- Default Location bottom sheet uses the same side margin and respects the larger of safe-area bottom inset or the shared margin.
- Center dialogs and fullscreen image viewers were intentionally not changed.
