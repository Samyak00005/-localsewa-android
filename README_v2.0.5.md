# Localsewa Android v2.0.5 — Provider Reviews UI Hotfix

Apply this incremental patch over **v2.0.4** by preserving the same paths and overwriting the included files.

## Changes

- Removed the Reviews page title and introductory subtitle from the top of the page.
- Refined the rating summary card with a clearer `Overall rating` hierarchy, `/5` context, stars, and review total.
- Replaced the bare review-count number beside `Customer feedback` with a compact `N reviews` chip.
- Replaced the technical read-only backend-contract copy with customer-facing completed-service feedback copy.
- Review dates now render as lightweight metadata with a calendar icon instead of isolated footer text.
- Summary, review, empty-state, and loading surfaces use the same **28dp Provider surface radius** established on the Profile page.
- No Customer screen/component files are included or changed.
